# Demo workflows

Эти сценарии безопасны для публичного показа на synthetic/redacted данных. Они показывают
продуктовую суть Л.Е.С., не раскрывая приватные проекты.

## 1. Dataset as a living notebook

Показать:

1. загрузку небольшого synthetic project corpus;
2. реестр файлов с типами данных: текст, таблицы, расчёты, графика, BIM, нормы, сметы;
3. вопрос “расскажи про объект”;
4. ответ, где модель использует карту датасета, но факты берёт из конкретных файлов;
5. клик “спросить по файлу” и strict ответ только по этому документу.

Критерий качества: модель не говорит “данных нет”, если файл есть в реестре; она добирает
документ или честно пишет, что файл найден, но ещё не прочитан в этом ответе.

## 2. Table arithmetic beats top-k RAG

Показать:

1. таблицу или ведомость с несколькими однотипными строками;
2. вопрос “суммарный метраж / количество / стоимость по позиции”;
3. расчёт по полной выгрузке Parquet/SQL;
4. source rows или trace, откуда взялась сумма.

Критерий качества: число считается кодом по всем строкам, а не языковой моделью по нескольким
похожим фрагментам.

## 3. Сметный режим без шаблонов

Показать:

1. модель сама раскладывает задачу, без объектного состава из кода;
2. код возвращает норм-навигацию, проверку единиц и расчётную трассу;
3. partial result остаётся partial, если не подтверждены критичные условия;
4. ресурсный artifact показывает ОЗП, ЭМ, ЗПМ, материалы, НР/СП, источники цен, missing flags.

Критерий качества: система не продаёт partial как готовую ЛСР и не добавляет объектные разделы
кодовым шаблоном. Модель спрашивает или считает по явно разрешённым допущениям.

Граница показа сметчику: [smeta-expert-review.md](smeta-expert-review.md).

## 4. Normcontrol report

Показать:

1. synthetic document package;
2. запуск СПДС/normcontrol review;
3. JSON/HTML/XLSX report;
4. normalized remarks and human decision status.

Критерий качества: формализуемые проверки делает код, модель связывает evidence and wording,
а финальное инженерное решение остаётся у человека.

## 5. CAD/BIM graph viewer

Показать standalone viewer на synthetic graph:

- элементы;
- свойства;
- связи;
- поиск / подсветка;
- переход от вопроса в чате к объекту графа.

Критерий качества: viewer не требует реальных клиентских моделей и не раскрывает private geometry.
