# ЛЕС 0.30.1 — evidence-first RAG и лёгкие обновления

- Дата выпуска: 30 августа 2026 года
- Версия продукта: `0.30.1`
- Номер сборки: `641`
- Версия desktop package: `5.1.641`

## Что изменилось

- выбранный датасет, вложения или явный режим «все источники» задают точную область поиска;
- когда источники не выбраны, ЛЕС общается как обычный локальный ИИ и не подмешивает корпус по словам вопроса;
- production native RRF собирает evidence до первого вызова модели, а модель может продолжать поиск по тому же RAG;
- ответ не подменяется semantic answer cache, кодовым `NO_DATA` или кодовой редактурой инженерного вывода;
- trace показывает, какие фрагменты и источники фактически получила модель;
- интерфейс Совушки использует читаемую системную типографику, нормальный базовый размер и единый стиль навигации;
- лёгкий updater больше не зависит от Docker, сохраняет пользовательские данные и запускает каждую patch-task ровно один раз.

## Как устанавливается

Для новой установки используется полный bootstrap `0.30.0`. После первого запуска встроенный updater
устанавливает этот кумулятивный патч и доводит систему до `0.30.1 / build 641`. Повторно скачивать
полный NSIS-установщик не требуется.

Обновление содержит только совместимые runtime-файлы. Python/uv runtime, внешние модели, Qdrant,
датасеты, индексы, память и пользовательские настройки не переустанавливаются.

## Проверка выпуска

Точный release commit проходит `make verify`, `make test`, updater gate, Tauri compile-check,
изолированные apply/rollback checks и живую установку поверх действующей `0.30.1 / build 639`
на Legion. После обновления `/api/version` сообщает `0.30.1 / build 641`, runtime aligned,
а updater подтверждает `user_data_untouched: true`.
