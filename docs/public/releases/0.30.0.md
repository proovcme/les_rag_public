# ЛЕС 0.30.0 — рабочий bootstrap обновлений

- Дата выпуска: 29 августа 2026 года
- Версия продукта: `0.30.0`
- Номер сборки: `634`
- Версия desktop package: `5.1.634`

## Что исправлено

- обычный чат вызывает точную модель, назначенную на роль «Ответы»; имя и размер модели не участвуют в маршрутизации;
- выбранный датасет остаётся точной областью ответа и не расширяется до почты или остальных наборов;
- в ответе видны фактически использованные подключение модели и датасеты;
- ошибка основной модели больше не маскируется сообщением об отсутствующем fallback;
- таймаут OpenAI-compatible модели синхронизирован: по умолчанию 300 секунд, значение можно переопределить через реестр среды;
- restrictive OpenAI-compatible серверы, принимающие system message только первым сообщением, поддерживаются совместимым повтором запроса;
- native Qdrant URL вынесен рядом с подключениями моделей; Docker не требуется и не используется;
- основной native RRF показывается независимо от необязательных RAPTOR и ColBERT;
- статусы RAPTOR/ColBERT переведены на пользовательский язык без внутренних error codes и путей;
- кнопка «Обновить ЛЕС» находится в шапке, проверка GitHub Releases выполняется после запуска и затем раз в сутки;
- установка обновления остаётся явным действием пользователя и сохраняет пользовательские данные;
- конкурирующий редактор системных промптов убран из «Инструментов»: пользовательский промпт задаётся профилем.

## Важно

`0.30.0` — полный bootstrap-installer нового канала обновлений. После него совместимые исправления приложения могут устанавливаться лёгкими runtime-патчами без повторной полной сборки Tauri. Полный installer остаётся нужен только для несовместимого изменения desktop bootstrap, встроенного Python/uv runtime, зависимостей или формата установщика.

Qdrant, модели и Ollama остаются внешними пользовательскими компонентами. ЛЕС подключается к ним по указанным адресам, не устанавливает Docker и не переносит пользовательские индексы.

## Проверка выпуска

Публикация разрешена только после зелёных contract/behavior/updater gates, Windows Tauri/NSIS build, установки exact artifact на Legion и живой приёмки native RRF, назначенной answer model, точной области датасета и механизма обновлений.
