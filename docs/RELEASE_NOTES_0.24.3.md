# Release notes 0.24.3

Чистая Windows-установка получает проверенный нормативно-ресурсный baseline ГЭСН/ФСЭМ внутри установщика и больше
не зависит от данных Mac или полного скрейпа норм при первом запуске. Сборка и live smoke останавливают
выпуск при отсутствии provenance, несовпадении SHA, менее 40 000 норм или менее 1 500 строк ФСЭМ;
существующая пользовательская база никогда не перезаписывается молча.

Региональные Сплит-формы, индексы и КАЦ/КП в универсальный EXE не зашиваются: они зависят от субъекта,
ценовой зоны и периода. До явного выбора/загрузки ценовой книги ЛЕС может выдать нормы и ресурсный расход,
но отсутствующие цены остаются `MISSING`; полная рублёвая смета не обещается. ARTEL в выпуск не входит.

Windows shell больше не теряет причину за generic `bootstrap exit code: 1`: JSON-status пишется без BOM, legacy BOM читается
толерантно, stale status очищается, а launcher stdout/stderr сохраняются в `%LOCALAPPDATA%\LES\logs` и показываются в UI.
PowerShell получает обычный `C:\…`-путь bootstrap вместо несовместимого verbatim `\\?\C:\…`.
Недоступный или повреждённый baseline больше не блокирует запуск всего ЛЕС: смета помечается как ограниченная,
а чат, документы и UI запускаются; выпускной clean-install smoke всё равно требует полный verified baseline.

В чате убран отдельный нижний подвал композера: выбор области, вложение, дополнительные действия и отправка
подняты прямо в нижний правый ряд существующей серой карточки режима; клавиатурная подпись удалена, кнопки остаются ≥40 px.
