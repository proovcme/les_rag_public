# ЛЕС 0.24.2

- Усилен model-owned сметный контракт: для выбранной нормы модель фиксирует сопоставление технологии,
  условий, ресурсов и межстрочных пересечений.
- Аналоги требуют явных ограничений, а изменения ресурсного состава — проверяемого основания.
- РИМ-XLSX корректно показывает метод расчёта, официальное название нормы вместе с описанием ВОР и
  оставляет отсутствующие цены пустыми.
- Windows-пакет ЛЕС не включает отдельный продукт ARTEL, его инструменты, fixtures и тесты.

Расчёт по-прежнему выполняется кодом после профессионального решения модели. ARTEL выпускается
отдельным установщиком и не является частью этого релиза ЛЕС.
