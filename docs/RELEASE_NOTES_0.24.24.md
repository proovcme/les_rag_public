# ЛЕС 0.24.24 / build 445

Сметный skill полностью владеет профессиональным решением модели. Python больше не заставляет
модель повторно выбирать норму из-за неполной анкеты, непрочитанной карточки или несовместимой
единицы и не дополняет exact/analog, applicability, ограничения либо ресурсные причины за модель.

- локальный пакет содержит только свои строки и `neighbor_context`, без чужих `work_id` всей ВОР;
- `submit_lsr_mapping` принимает модельную ревизию инкрементально и сохраняет её буквально;
- профессиональные требования к технологии, поиску, coverage и аналогам находятся в skill;
- вычислительные несовместимости становятся построчными blockers и не валят остальную ЛСР;
- Python больше не скрывает tools и не повторяет свободный текст обязательными tool-reminders;
- native Ollama tool results используют `tool_name`, поэтому следующий ход видит, какой tool вернул evidence;
- batch-level `page/limit` Qwen больше не теряются, идентичный deterministic tool-call останавливается сразу;
- Gemma 4 проходит одиночную строку, но пакет из пяти строк пока не является надёжным production-default.
