# LES external integration surface

Канонический публичный сетевой контракт находится в [LES_API_AND_EXTERNAL_INTEGRATIONS.md](LES_API_AND_EXTERNAL_INTEGRATIONS.md).

Этот файл сохранён как совместимая точка входа для старых ссылок. Прежний machine-specific inventory удалён: частные IP, состояние конкретных provider и снимок количества маршрутов не являются документацией продукта. Точную API-схему работающего узла предоставляет `GET /openapi.json`.
