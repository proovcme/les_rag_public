## Неприкосновенные границы

- Модель отвечает, связывает источники, выбирает инструменты и принимает профессиональные решения.
- Код сужает явно выбранную область, читает exact evidence, проверяет provenance/единицы и считает.
- Прайс, норма, таблица или vision-наблюдение являются материалом модели, а не готовым решением кода.
- Настройка длины меняет только потолок генерации и явную пользовательскую директиву; стандартный
  режим сохраняет прежний потолок 8 192 токена.
- Выбор нескольких документов не склеивает их в новый источник и не расширяет поиск за выбранные файлы.
- Vision получает только выбранную страницу/область исходного PDF и возвращает наблюдение с файлом
  и номером страницы. Код не интерпретирует чертёж вместо модели.

Mac live-проверка на реальном листе ЭОМ закрыла транспорт: bounded render 1 600 px → native Ollama
`/api/chat` → `qwen3.5:9b` с `think=false` → непустое наблюдение и `file#page`. Полный лист 2× дал
таймаут и не считается допустимым штатным режимом; OpenAI-compatible endpoint дал пустой content
из-за reasoning и также исключён для этого инструмента.

## Служебные датасеты

`Нормативы и чек-листы`, `Прайсы` и `Сметные источники` — обычные contract-versioned системные
датасеты в общей named collection. Их можно искать в «Документах», выбирать в области чата и
пополнять через штатный upload. Сметный режим автоматически добавляет system scope модуля `smeta`,
поэтому модель видит прайсы как evidence; отсутствие цены остаётся построчным MISSING, а не причиной
выдумывать цену или блокировать всю работу.

## Доставка изменений

Быстрый VPS-патч разрешён только для replaceable Python/UI/prompts/docs без зависимостей, схем,
baseline, Rust/Tauri/NSIS и нативных компонентов. Патч обязан иметь base/target commit, allowlist,
SHA-256, backup, compile/smoke и автоматический rollback. Пока такого инструмента нет, ручной SCP
не является штатным обновлением. Всё остальное проходит Git → Windows build → isolated smoke →
production Legion smoke → publish.
