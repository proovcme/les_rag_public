# ЛЕС 0.24.22

- Windows-установщик содержит проверенные SHA-256 portable CPython 3.13.12 и `uv.exe`; отдельная установка Python или uv больше не требуется.
- Первый `uv sync` использует системные сертификаты Windows, повторяет кратковременные сетевые сбои, удаляет недосозданную `.venv` и показывает точную причину ошибки в журнале.
- В чате появилась кнопка «Остановить диалог», вернулись плавающие подсказки над вводом, а потоковый ответ больше не прижимает ленту вниз после ручной прокрутки.
- Сметная модель больше не обрезается скрытым лимитом 900 токенов и не повторяет один и тот же no-tool ход; выбранные моделью нормы сохраняются без кодового перевыбора.
- ЛСР читает нормативную SQLite и ФСЭМ напрямую из `%LOCALAPPDATA%\LES\data` в read-only режиме, не проходя через защищённый каталог установки.
- Установка с правами администратора явно выдаёт обычному пользовательскому процессу доступ к persistent state; сметная база больше не остаётся доступной только `SYSTEM/Administrators`.
- Шумовой PDF-фрагмент без BM25-термов больше не переводит весь документ в `ERROR`: сохраняются все валидные dense+sparse фрагменты.
