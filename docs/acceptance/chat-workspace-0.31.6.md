# Приёмка исправлений чата0.31.6

Дата: 2026-09-05. Предыдущий gate0.31.5 не доказывал удобство чата и попадание
мыши в поля. Ниже сохранены новые воспроизводимые проверки.

## Причины и проверки

- У установленного диалога проекта поле имело `pointer-events:none`; в центре
  поля `elementFromPoint` возвращал backdrop. После исправления общей панели
  возвращается input, `pointer-events:auto`. В изолированном UI через браузер
  введено «Проверка ввода — школа», проект сохранён и открыт его первый чат.
  На390px введено «Мобильная проверка» и нажата «Отмена»; диалог закрывается.
- На772×755 раньше переписка занимала306px, composer225px, ширина чата548px.
  После: переписка около445px, composer130px, чат772px. Проекты доступны
  через явную кнопку; на1280px боковая панель постоянно видна.
- С61 синтетическим проектом на1280×720: переписка409px, composer130px,
  создание проекта top153/bottom197px, footer bottom704px. На390×844:
  переписка433px, composer178px; при открытом списке создание bottom201px,
  footer bottom824px. Горизонтального/вертикального overflow страницы нет.
- На390px длинное имя проекта сначала растягивало шапку по одному символу;
  проверка поймала и закрыла дефект. Имя теперь обрезается одной строкой,
  действия шапки переносятся отдельной строкой.
- Временная база preview содержит116 обычных чатов и61 проект. Первичная
  отрисовка20 чатов, остальные через «Показать ещё». Тест раскрывает все114
  строк, включая переносы/кавычки/слэши; отдельный тест с60 проектами проверяет
  фиксированное создание, параллельность запросов и неизменные element ids.
  Открытие списка в browser automation заняло312ms, включая накладные расходы
  инструмента. Это единичное измерение, не общий latency benchmark продукта.
- Code review поймал скрытие старого активного чата за порцией20. Теперь активная
  сессия добавляется к видимой порции, даже если открыта через историю; тест
  проверяет смену проекта и активную строку25. Создание не требуется у не-admin.

## Повторяемый browser gate

На desktop и390px открыть список с длинной историей/множеством проектов,
прокрутить его, проверить видимость создания и Конфигурации. Открыть создание,
выполнить `tools/chat_workspace_ui_probe.js`, ввести название, сохранить,
проверить новый проект и его чат. Отдельно проверить отмену, Память,
Настройки ответа и ввод длинного сообщения. Проверять скриншот вместе с
геометрией: наличие элементов и зелёный pytest не заменяют эти действия.

## Границы

Backend, решения модели, retrieval и XLSX не менялись. Предыдущее доказательство
цикла9B относится к неизменному backend; повторный model benchmark здесь
не заявляется. Все синтетические проекты созданы только в `.test-tmp` preview.
Статус общего gate и установленного артефакта — RELEASE_LEDGER.
