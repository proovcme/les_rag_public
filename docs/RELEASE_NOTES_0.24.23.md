# ЛЕС 0.24.23 / build 444

Сметный document-agent теперь использует полный `skills/smeta/SKILL.md` как единственный
профессиональный контракт. Дублирующие предметные инструкции из Python и короткий
`runtime-agent.md` удалены.

- каждая выбранная норма содержит структурированную технологическую проверку;
- открытая строка требует доказанного повторного поиска и проверки карточек/coverage;
- неоткрытые нормы и несовместимые единицы возвращаются модели до расчёта;
- локальная модель работает небольшими транспортными пакетами без смешивания строк;
- уже принятые модельные решения не пересобираются при исправлении одной строки;
- код по-прежнему не выбирает нормы: он проверяет ссылки и единицы, считает и формирует XLSX.
