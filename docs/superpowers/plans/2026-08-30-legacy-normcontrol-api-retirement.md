# Legacy Normcontrol API Retirement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the unconsumed legacy `/api/normcontrol/*` router and align the engineer profile with the active `doc_review` tool while preserving the shared formal-check service.

**Architecture:** `normcontrol_service` remains an internal formal-check component used by document models and review services. Only the parallel two-route API is retired; the active `/api/doc-review/*` workflow and agent tool remain. `ProfileResolver` changes its stale `run_normcontrol` permission to the actually registered `doc_review` tool.

**Tech Stack:** Python 3.12, FastAPI, pytest, uv.

**Spec:** `ROADMAP_TO_V1.md`; `docs/MODULE_INDEX.md`; `docs/CODE_MAP.md`; `docs/ALGO-normcontrol.md`.

## Global Constraints

- Do not modify the algorithms in `proxy/services/normcontrol_service.py`, `proxy/services/doc_review_service.py`, `proxy/smeta_core/**` or RAG.
- Do not delete reports, datasets, decisions, review maps, Qdrant state or any user data.
- Preserve all `/api/doc-review/*` routes and the `doc_review` agent tool.
- Preserve `tests/test_normcontrol_service.py`; the service remains active.
- Work in the existing cleanup branch; do not create another branch or worktree.
- Use a failing effective route/profile contract before changing production code.
