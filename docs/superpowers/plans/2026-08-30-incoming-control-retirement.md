> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the unfinished incoming-control product island while preserving active field, task, file-map and decision workflows.

**Architecture:** Static consumers, current documentation and Git history show that incoming control consists only of one registered router, one isolated service and its own tests.
