# Сохранение результата и авторство поиска — кандидат975

**Цель:** устранить измеренные технические потери ответа и доказательств,
сохранив профессиональные решения модели. Это часть доведения ВОР/ЛСР,
а не доказательство точности норм или готовности заказчику.

**Основание:** действующий AGENTS владельца и установленные контроли974:
multifile_vor/run01, small7_lsr/run01, small7_b0/run01, small7_lsr/run02.
Их отрицательные квитанции не изменяются.

**Границы:** прежние FastAPI, ContextGovernor, общий RAG, job/event ledger,
XLSX writer. Новых зависимостей, предметных правил, таблиц БД, модельных
HTTP callsites и автоматических циклов нет. Только ROOT запускает тесты,
сборку и inference, последовательно; независимые агенты читают исходники.

- [x] Воспроизвести потерю одного самостоятельного JSON после заголовка.
  Сохранить ограничения на дубликаты, конкурирующие результаты, незакрытый
  JSON/fence, literal values и отдельную декларацию вида документа.
  Измеренный B0-ответ974 теперь разбирается в7строк без нового inference.
- [x] Отделить существующий буквальный proof_request от данных в required
  `PHASE_INSTRUCTION`. Сохранить цельный native reasoning exchange того же
  хода, прежний wire при None, count/cloud и честный overflow.
- [x] Различить новый пакет с индексом других работ, same-packet replay
  и explicit review. Не переписывать строки, роли, объёмы, IDs и evidence.
- [x] Удалить активное добавление code-authored queries. Совместимый кэш
  восстанавливать без поиска; иначе модель заново объявляет запросы ровно
  прежнего held packet. Старый план сохраняется в append-only event,
  неизвестное авторство не становится model. Чужой scope блокирует dispatch.
- [x] До первого proof-await сохранять завершённый публичный ответ и точные
  evidence bindings в held checkpoint без принятия строк и выдачи IDs.
  Явное продолжение возвращается в ту же bounded proof-стадию, использует
  сохранённые карточки/reads и не повторяет query/initial-answer. Старое
  native thinking не переносится в новый человеческий ход. Остановка,
  CloudBudgetStop, ошибочный terminal и отказ admission сохраняют checkpoint.
