# API Surface Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the superseded prompt editor API and the ungoverned structured-extraction API while preserving the canonical profile surface and internal extraction service.

**Architecture:** The public FastAPI surface must expose one user-owned prompt/skill control through immutable `/api/profiles` revisions. Structured extraction remains an internal service used by governed LES workflows; it is no longer callable through an unauthenticated generic HTTP endpoint.

**Tech Stack:** Python 3.12, FastAPI, pytest, uv.

**Spec:** `ROADMAP_TO_V1.md`; `docs/modules/chat-profiles.md`; `docs/CODE_MAP.md`.

## Global Constraints

- Do not modify `proxy/smeta_core/**` or estimating behavior.
- Do not restart runtime services or touch user data.
- Preserve `proxy/services/prompt_registry_service.py` for internal role/system prompts.
- Preserve `proxy/services/extract_service.py` for internal governed consumers.
- Use a failing API-surface contract test before removing routes.
