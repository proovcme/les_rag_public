ЛЕС 0.25.0 — крупное обновление работы с документами, сметами и локальной почтой.

- Сметный модуль получил отдельный проверяемый контур ФГИС/ФСНБ: гибридный поиск, объединение результатов, повторное ранжирование и чтение точных строк нормативных таблиц.
- Общий поиск теперь предназначен только для документов пользователя и не смешивает их со служебными сметными данными.
- Полные таблицы норм читаются без потери строк. Выбор нормы остаётся за моделью и пользователем, а код проверяет источники и выполняет расчёт.
- Окно «Документы» упрощено: доступны найденные фрагменты и переход к оригиналу файла.
- Генератор документов и CAD/BIM вынесены в отдельные рабочие вкладки.
- Генератор документов начинает работу с выбранного датасета, тома и файлов-оснований и умеет извлекать название и адрес объекта из проектного листа.
- Просмотр почты находится в рабочем интерфейсе, а подключение и настройка почтовой сборки — в конфигураторе.
- Сборщик Outlook больше не перечитывает всю историю после завершения первоначального импорта; фоновая проверка выполняется реже.
- Добавлены автоматические проверки и нативные сборки для macOS и Windows. Публикация блокируется, если одна из платформ не прошла полный контроль.

Смета остаётся проверяемым черновиком до подтверждения пользователем.
