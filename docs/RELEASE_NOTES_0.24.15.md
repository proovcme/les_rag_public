# ЛЕС 0.24.15

- Добавлен общий для всех Windows-установок канал быстрых проверяемых патчей через `les.ovc.me`.
- Патч проверяет base/target SHA, делает резервную копию, перезапускает ЛЕС и откатывается при ошибке.
- В настройках показаны однозначные действия «Проверить патч» и «Установить» с живым статусом.
- Публичный `les.ovc.me` переведён с живого ЛЕС на статический лендинг; рабочий доступ остаётся локальным/ZeroTier.
