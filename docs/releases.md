# Выпуски ЛЕС

Этот файл больше не дублирует сотни исторических версий. История сохранена в Git.

Текущий контракт версии хранится только в [`config/version.json`](../config/version.json):

- `product_version` — пользовательская версия `X.Y.Z`;
- `build_number` — монотонный номер сборки Windows;
- `desktop_version` — внутренняя версия Tauri/NSIS для корректного обновления;
- `harness_schema_version` — версия внутреннего контракта строительного контура.

Где смотреть фактическое состояние:

- [`RELEASE_LEDGER.md`](RELEASE_LEDGER.md) — текущий выпуск, commit, проверка и развёртывание;
- [`SOFTWARE_VERSIONS.md`](SOFTWARE_VERSIONS.md) — версии Qdrant, Ollama, Python, uv, моделей и сборочных средств;
- `GET /api/version` — версия и commit реально запущенного экземпляра;
- GitHub Releases — опубликованные установщики и контрольные суммы.

Исправительный выпуск создаётся только командой `make patch-release`; она проверяет чистый отправленный
commit, выполняет гейты, собирает и устанавливает EXE в изолированный каталог на Windows, запускает
живую проверку и лишь затем может опубликовать установщик.
