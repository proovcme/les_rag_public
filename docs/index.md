# ЛЕС — публичная документация

ЛЕС — локальная и распределённая система для работы с проектными документами и проверяемыми источниками. Совушка даёт интерфейс, backend ЛЕС обрабатывает документы и управляет RAG/памятью/инструментами, а модели и Qdrant подключаются как независимые сервисы.

Это evidence harness, а не автономный проектировщик: модель понимает вопрос и связывает сведения, код извлекает и считает, источники подтверждают результат, решение принимает человек.

## Статус 0.29.3

Готовы Windows installer, Совушка для desktop/browser/PWA, внешний Qdrant с native dense+sparse RRF, реестр OpenAI-compatible моделей и разделённые runtime-профили. Studio, CAD/BIM production UI, основной почтовый workflow и one-click VPS deployment пока не заявляются готовыми.

В публичном репозитории нет пользовательских документов, писем, нормативных корпусов, индексов, Qdrant snapshots, runtime databases, моделей или секретов.
