# ЛЕС — публичная документация

ЛЕС — локальный помощник ГИП/РП для работы с многолетними проектными документами и проверяемыми источниками. Совушка даёт интерфейс, backend управляет RAG, памятью и инструментами, а модели и Qdrant подключаются как независимые сервисы.

Если источники выбраны, они являются правдой для ответа; если не выбраны, возможен обычный диалог с локальной моделью. Модель исследует и связывает, RAG даёт evidence, код считает и оформляет, решение принимает человек.

## Статус 0.30.1

Опубликованы bootstrap 0.30.0 и кумулятивный patch 0.30.1. Совушка, внешний Qdrant с native dense+sparse RRF, явный выбор document scope и реестр OpenAI-compatible моделей работают; качество фактически переданного модели evidence остаётся главным направлением приёмки.

В публичном репозитории нет пользовательских документов, писем, нормативных корпусов, индексов, Qdrant snapshots, runtime databases, моделей или секретов.

## Для разработки

Текущая правда читается в порядке `AGENTS.md` → `MODULE_INDEX` → `CODE_MAP` → документ конкретного
модуля или `ALGO-*`. Старые планы, статьи и отчёты находятся в [архиве](archive/README.md) и не
являются инструкциями. Канонические ссылки проверяются `tools/documentation_contract.py`.
