# Л.Е.С. — локальная работа с проектными документами

Л.Е.С. индексирует документы проекта, находит подтверждающие фрагменты и передаёт их выбранной вами языковой модели. Ответ остаётся связан с файлами, страницами, листами и строками источника.

> Модель читает, связывает сведения и формулирует вывод. Код извлекает точные строки, проверяет единицы и считает. Инженерное или сметное решение подтверждает человек.

## Установить на Windows

1. Откройте [последний публичный выпуск](https://github.com/proovcme/les_rag_public/releases/latest).
2. Скачайте `LES-Setup.exe` и, при необходимости, сверьте файл `LES-Setup.exe.sha256`.
3. Запустите установщик. Права администратора, Git, Python и uv не нужны.
4. Первый запуск распакует встроенную среду ЛЕС и откроет экран совместимых компонентов.
5. Выберите движок ответа в настройках ЛЕС и подключите компоненты поиска, которые вам нужны.

Windows может показать предупреждение для неподписанного приложения: у публичного тестового выпуска пока нет Authenticode-сертификата. Не скачивайте установщик из сторонних источников.

### Что входит, а что выбирает пользователь

| Роль | Входит в `LES-Setup.exe` | Совместимые варианты |
|---|---|---|
| Ядро ЛЕС | Да: приложение, Python, uv и lock-привязанные Python-зависимости | Ничего устанавливать отдельно не нужно |
| Движок ответа | Нет | Ollama, FreeToken, Lemonade, OpenAI-compatible API |
| Embeddings для поиска | Нет | Ollama с `bge-m3`, Lemonade-compatible endpoint; другие совместимые endpoints развиваются |
| Индекс документов | Нет | Qdrant; текущий простой локальный путь — Docker Desktop |

ЛЕС показывает доступность этих компонентов, но не устанавливает, не запускает и не выбирает сторонний продукт за пользователя. Отсутствующий компонент не мешает открыть ЛЕС: недоступная функция получает явный статус внутри приложения.

FreeToken в текущем Windows-профиле отвечает за генерацию, а embeddings получает от отдельного провайдера. Поэтому работающий FreeToken сам по себе ещё не означает готовность поиска по документам.

## Что умеет ЛЕС

- загружать и индексировать PDF, DOCX, XLSX, CSV и другие проектные файлы;
- искать одновременно по смыслу и точным обозначениям через dense + sparse native RRF;
- отвечать по одному или нескольким выбранным датасетам с кликабельными источниками;
- использовать нормы и коммерческие расценки как обычные отдельные RAG-датасеты;
- продолжать диалог с учётом истории чата;
- работать с таблицами, почтой, документами, CAD/BIM-проекциями и нормоконтролем;
- показывать `MISSING`, `BLOCKED` и конфликт источников вместо выдуманного результата.

Сметные нормы модель подбирает по найденным карточкам и их составу работ. ЛЕС не делает выбор нормы невидимым кодовым правилом и не считает неподтверждённый результат окончательной сметой.

## Данные и приватность

По умолчанию приложение слушает только loopback-адреса. Пользовательские документы, история, настройки, индексы и журналы находятся в `%LOCALAPPDATA%\LES` и не входят в обновляемое дерево программы `%LOCALAPPDATA%\Programs\LES`.

Облачный provider передаёт ему содержимое запроса и найденный контекст. Локальные Ollama, FreeToken и Lemonade позволяют оставить генерацию на рабочей машине. Подробно: [границы данных](docs/public/privacy-and-data-boundaries.md).

## Если установка или запуск не удались

Откройте [диагностику Windows](docs/public/windows-troubleshooting.md). В ней собраны коды ошибок, безопасные проверки, восстановление и пути журналов. Основной журнал первого запуска:

```text
%LOCALAPPDATA%\LES\logs\bootstrap.log
```

## Статус публичного теста

- Основной проверяемый пользовательский выпуск — Windows 10/11 x64.
- macOS и Linux пока остаются developer/reference-контурами; их полноценная продуктовая поддержка находится в roadmap.
- Модельные движки и веса не включены в установщик.
- Qdrant сейчас проще всего запускать через Docker Desktop.
- Windows installer пока не подписан Authenticode.
