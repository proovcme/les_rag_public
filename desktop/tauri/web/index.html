Настройка Л.Е.С.

Проверим чистую Windows, установим недостающие программы и подключим выбранную вами локальную модель.

Проверяю…
01

Встроенная среда

Python и uv входят в установку. ЛЕС проверяет их контрольные суммы и готовит окружение автоматически.

Подготавливаю…
02

Ollama

Локальный движок моделей. Если его нет, мастер запустит обычную установку через winget.

Проверяю…
03

Модель для ответов

Скачайте любую модель самостоятельно. Для смет и инструментов рекомендуем qwen3.5:9b.

Ищу модели…
ollama pull qwen3.5:9b
04

Поиск по документам

Для совместимого векторного поиска ЛЕС отдельно использует embedding-модель bge-m3.

Проверяю…
ollama pull bge-m3
05

Docker и Qdrant

Docker хранит локальный индекс документов. После установки Docker Desktop может попросить включить WSL 2 или перезагрузиться.

Проверяю…
06

Готовность

Запуск станет доступен, когда Ollama и Docker работают, а обе модели установлены.

Собираю состояние…

Рекомендации после запуска

  • Оставьте Ollama и Docker Desktop включёнными во время работы с ЛЕС.
  • Для 16 ГБ видеопамяти начните с qwen3.5:9b; более крупную модель выбирайте только после проверки скорости.
  • Вернуться сюда можно из трея: «Настройка и справка». Документы и чаты при этом не удаляются.
Отсутствие компонента не закрывает приложение — мастер покажет, что именно требуется.
