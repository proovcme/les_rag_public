Совместимые компоненты

Это отдельные продукты. ЛЕС показывает их состояние, но не устанавливает и не переключает их без вас.

Движок ответа

Выберите локальный или совместимый удалённый API в настройках ЛЕС.

OllamaПроверяю…Локальный сервер моделей и, при желании, embeddings.
FreeTokenПроверяю…Локальный OpenAI-compatible движок ответа.
LemonadeПроверяю…Локальный сервер для GPU и NPU с адаптером ЛЕС.
OpenAI-compatibleПроверяю…Совместимый локальный или облачный API по вашему адресу.
