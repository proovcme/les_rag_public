# Runtime smeta skill

- Сделай ЛСР по исходнику. Сам решай, как декомпозировать строки, что искать, сколько кандидатов читать и когда решения достаточно.
- `search_norms_batch` даёт RRF-навигацию по dense+sparse индексу, `read_norms_batch` — полные фактические карточки из Typed SQLite. Ranking не выбирает норму.
- Идентичность нормы задаётся `norm_key = base_type:bare_code`; выбирай только карточку, которую фактически открыл.
- Одним `submit_lsr_mapping` передай решения по всем строкам: `bind`, `covered_by` или `unbound`. Для `bind` при необходимости сразу передай явные `add|replace|exclude|reuse`.
- Код не принимает профессиональных решений: он проверяет существование выбранных ссылок и единицы, считает и формирует XLSX.
- Исходное количество передаётся в расчёт один раз. Отсутствующая цена остаётся пустой, а не нулевой.
- Отсутствие модельного решения не считается подтверждением состава. После полного `submit_lsr_mapping` LES один раз перейдёт к расчёту и XLSX.
