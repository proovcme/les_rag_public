# Runtime smeta skill

- Сделай ЛСР по исходнику. Сам решай, как декомпозировать строки, что искать, сколько кандидатов читать и когда решения достаточно.
- `search_norms_batch` даёт RRF-навигацию по dense+sparse индексу, `read_norms_batch` — полные фактические карточки из Typed SQLite. Ranking не выбирает норму.
- Идентичность нормы задаётся `norm_key = base_type:bare_code`; выбирай только карточку, которую фактически открыл.
- Одним `submit_lsr_mapping` передай решения по всем строкам: `bind`, `covered_by` или `unbound`. Для каждого `bind` сначала сопоставь исходную технологию с названием, измерителем, составом работ и ресурсами открытой нормы; зафиксируй совпавшие, отсутствующие и лишние операции, посторонние ресурсы, проверенные и неразрешённые условия.
- Проверь решения между строками: одна операция или подготовительный слой не должны повторно оплачиваться другой выбранной нормой. Пересечения перечисли по `work_id` и явно укажи, как они разрешены через `bind`, `covered_by` или `unbound`.
- Составная строка не становится `exact`, если открытая норма покрывает только часть технологии. Если недостающую часть нельзя честно связать отдельным решением, оставь строку `unbound`; ranking и похожее название не являются доказательством применимости.
- Для аналога обязательны конкретные ограничения. Для изделия или материала сверяй определяющие характеристики исходника с карточкой/источником цены; неизвестные характеристики не называй точным совпадением.
- Для `bind` при необходимости сразу передай явные `add|replace|exclude|reuse`. Любое ресурсное действие требует конкретного основания `basis_ref`; субъективное «не требуется» без нормы, техчасти или проектного источника недопустимо.
- Код не принимает профессиональных решений: он проверяет существование выбранных ссылок и единицы, считает и формирует XLSX.
- Исходное количество передаётся в расчёт один раз. Отсутствующая цена остаётся пустой, а не нулевой.
- Отсутствие модельного решения не считается подтверждением состава. После полного `submit_lsr_mapping` LES один раз перейдёт к расчёту и XLSX.
