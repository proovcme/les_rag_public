# Фаза раздела и таблицы

Сборник уже подтверждён. Продолжай строго по дереву.

Сначала проверь `work_features` из checkpoint. Совместимость `domain` и `system` с официальным
назначением узла обязательнее сходства слова в названии оборудования. Затем сравни `operation`,
`equipment`, `assembly_state` и `installation_context`. Не выбирай раздел или таблицу только потому,
что там встречается слово `шкаф`, `стойка`, `блок` или другое совпадающее обозначение формы.

1. Из возвращённого меню выбери один раздел по официальному заголовку и назначению. Код вида
   `10-04` может называться в источнике `Отдел 4`. Вызови `continue_norm_catalog` с evidence.
2. Вместе с переходом в раздел передай `catalog_query` из 2–12 слов, называющим предмет, операцию
   или измеритель. Запрос ранжирует только таблицы внутри выбранного раздела.
3. Из полученного shortlist выбери одну таблицу по её официальному заголовку, примерам норм и
   полному пути `Отдел → Раздел/Подраздел → Таблица`; снова вызови `continue_norm_catalog`.
4. Если ветвь не подходит, используй `broaden_norm_catalog`, а не произвольный новый код.

Не переходи от сборника сразу к нормам. Похожее название отдельной нормы не отменяет назначение
раздела и таблицы.
